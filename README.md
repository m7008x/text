# สมุดคะแนน (Student-Score-Lookup)

ระบบตรวจสอบผลการเรียน ธีมสมุดจด: นักเรียนกรอกรหัสแล้วดูคะแนนทุกวิชา ส่วน admin เพิ่ม แก้ไข และลบข้อมูลได้
ทำงานบน **Vercel** (หน้าเว็บ + Serverless API) และ **Supabase** (ฐานข้อมูล PostgreSQL)

## ความสามารถ

**นักเรียน**
- กรอก ID STD หรือเลือกจากรายการ (ช่วงรหัสตั้งได้ใน `public/config.js` ค่าเริ่มต้น **68319030001 – 68319030020**)
- เห็นรูป รายวิชาทั้งหมด คะแนน เกรด กราฟ และคะแนนเฉลี่ย
- วิชาที่ยังไม่มีคะแนนจะแสดงว่า "ยังไม่มีคะแนน"

**admin**
- **Insert / Edit / Delete** คะแนน: เลือกรหัสนักเรียน, วิชา, ใส่คะแนน (0–100) และลิงก์รูป (Pic)
- **จัดการรายวิชา**: เพิ่มวิชาได้ไม่จำกัด แก้ชื่อวิชา (คะแนนเดิมเปลี่ยนชื่อตาม) และลบวิชา (ลบคะแนนของวิชานั้นด้วย)
- นักเรียน 1 คน มีคะแนนได้ 1 รายการต่อวิชา
- รูปเป็นของนักเรียนแต่ละคน ใส่ครั้งเดียวใช้กับทุกวิชา
- ค้นหา กรอง และ Export CSV

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `public/config.js` | **ตั้งค่าเว็บที่เดียว**: ชื่อเว็บ, ชื่อโรงเรียน, รหัสนักเรียนคนแรก, จำนวนนักเรียน |
| `public/index.html` | หน้าเว็บทั้งหมด (นักเรียน + admin) |
| `api/login.js` | เข้าสู่ระบบ admin |
| `api/scores.js` | ค้นหา / เพิ่ม / แก้ไข / ลบคะแนน |
| `api/subjects.js` | ดู / เพิ่ม / แก้ชื่อ / ลบรายวิชา |
| `api/_lib.js` | โค้ดที่ใช้ร่วมกัน (สร้างรายการรหัสจาก config, ตรวจ token, เชื่อม Supabase) |
| `supabase/schema.sql` | สร้างตาราง `subjects` และ `student_scores` |

## วิธีติดตั้ง

1. **Supabase**: สร้างโปรเจกต์ แล้วเปิด **SQL Editor** วางเนื้อหาไฟล์ `supabase/schema.sql` แล้วกด Run
   (ถ้ามีตาราง `student_scores` จากเวอร์ชันเดิมอยู่แล้ว ดูหมายเหตุในไฟล์)
2. **Vercel**: Import repo นี้ แล้วตั้ง Environment Variables

   | ชื่อ | ค่า |
   |---|---|
   | `SUPABASE_URL` | Project URL จาก Supabase > Settings > API |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role key จากหน้าเดียวกัน |
   | `ADMIN_USERNAME` | ชื่อผู้ใช้ admin |
   | `ADMIN_PASSWORD` | รหัสผ่าน admin |
   | `ADMIN_SECRET` | ข้อความยาวๆ แบบสุ่ม ใช้เซ็น token |

3. Deploy แล้วเข้าเว็บ ไปที่แท็บ **จัดการระบบ (Admin)** → เพิ่มวิชา → เพิ่มคะแนน

> **ต้องตั้ง** `ADMIN_USERNAME`, `ADMIN_PASSWORD` และ `ADMIN_SECRET` ทั้งสามตัว ไม่มีรหัสเริ่มต้นในโค้ด ถ้าขาดตัวใดตัวหนึ่ง หน้า Admin จะเข้าไม่ได้
> สร้าง `ADMIN_SECRET` แบบสุ่มได้ด้วยคำสั่ง `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

## ปรับเป็นของตัวเอง

แก้ไฟล์ `public/config.js` ไฟล์เดียว:

```js
siteName: 'สมุดคะแนน',          // ชื่อเว็บ
schoolName: 'โรงเรียนของเรา',    // ชื่อโรงเรียน / ห้อง
firstStudentId: '68319030001',  // รหัสนักเรียนคนแรก
studentCount: 20,               // จำนวนนักเรียน
```

หน้าเว็บ, API และข้อความทุกจุดจะเปลี่ยนตามทันที ไม่ต้องแก้ SQL

## ความปลอดภัย

- ไม่มีรหัส admin หรือ secret เริ่มต้นฝังในโค้ด
- เทียบรหัสผ่านและลายเซ็น token แบบใช้เวลาคงที่ (กันการเดาจากเวลาตอบกลับ)
- หน่วงเวลาเมื่อรหัสผิด และ token หมดอายุใน 12 ชั่วโมง
- API ใช้ได้เฉพาะ `SUPABASE_SERVICE_ROLE_KEY` (ตาราง Supabase เปิด RLS ไว้ เข้าตรงจากภายนอกไม่ได้)
